The TechBridge Internship

30 days. 8 tasks. One working platform.

Once a program ends, the internship starts. It's split into 8 practical tasks spread across 30 days — each one shipping a real piece of the TechBridge platform, each one a little harder than the last. This page is the map.

Task 1 · Day 1 Completed

Build the TechBridge Homepage

Beginner

Create the first version of the TechBridge website using HTML and CSS.

What it involved

The foundation the rest of the platform sits on — hero, about, programs teaser, internship section, community and contact, hand-built and responsive from the first line of CSS.

Task 2 · Day 4 Completed

Build the TechBridge Programs Experience

Beginner → Intermediate

Create a Programs experience that presents TechBridge's available learning programs.

What it involved

A dedicated page breaking down both learning tracks — Data Analytics and Web Development — with the skills each one builds and a clear next step into the internship.

Task 3 · Day 8 Completed

Build the Internship Tasks Experience

Beginner → Intermediate

Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

What it involved

This page — a day-by-day map of all 8 tasks, showing what's done, what's actively being worked on, and what's still ahead, without needing any JavaScript to read it.

Task 4 · Day 11 Completed

Build an Interactive Internship Roadmap

Beginner → Intermediate

Use JavaScript to let visitors switch between the Data Analytics and Web Development internship tracks without refreshing the page.

What it involved

A track switcher backed by JavaScript — pick a track and see its full 8-task journey, the days each task lands on, and how the difficulty ramps up, all without a page reload.

Task 5 · Day 15 Completed

Build the TechBridge Challenge Hub

Beginner → Intermediate

Create an interactive Challenge Hub where visitors can browse, filter and open practical challenges from both TechBridge tracks.

What it involved

Eight realistic briefs across Data Analytics and Web Development, filterable by track and difficulty, searchable by keyword, with the full brief opening in a modal — all without a page reload.
